# Web Development – Activity-Based Learning

This repository contains three beginner-friendly HTML5 and CSS3 website projects prepared for a first-year Web Development assignment.

## Projects
1. `Project-1-Personal-Portfolio` – Personal Portfolio Website
2. `Project-2-Bakery-and-Cake-Shop` – Bakery and Cake Shop Website
3. `Project-3-Tourism-and-Heritage` – Tourism and Heritage Information Website

## Technologies
- HTML5
- CSS3 (included in each page)
- Responsive layouts for desktop and mobile screens

## Run the projects
Open a project folder and double-click `index.html` to view it in a web browser. An internet connection is needed for online images.

## Before submission
- Replace sample names, college and contact details in Project 1.
- Review sample bakery details in Project 2.
- Open all three pages and check that they display correctly.
- Capture your own screenshots and add them to the `Screenshots` folder.
- Add your name, roll number, branch and section if required by your teacher.

## Syllabus concepts
HTML document structure, elements, images, lists, hyperlinks, anchor navigation, HTML5 semantic structure, CSS syntax, colors, typography, text properties, box model, width, height, padding, margin, backgrounds, viewport, responsive/mobile-first design, and basic UI/UX principles.
